# Machine Learning Laboratory

## Overview

This repository contains the Machine Learning Laboratory experiments completed as part of the **B.E. Computer Science and Engineering** curriculum. The programs are implemented using Python and demonstrate the practical application of various Machine Learning algorithms and data analysis techniques.

The purpose of this repository is to provide hands-on experience in building, training, and evaluating machine learning models using real-world datasets.

---

## Objectives

- Understand the fundamentals of Machine Learning.
- Implement various supervised and unsupervised learning algorithms.
- Perform data preprocessing and feature engineering.
- Analyze datasets through visualization.
- Evaluate model performance using standard metrics.
- Gain practical experience with Python-based ML libraries.

---

## Technologies Used

- Python 3.x
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

---

## Laboratory Experiments

This repository includes experiments related to:

- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Naive Bayes Classification
- K-Means Clustering
- Hierarchical Clustering
- Principal Component Analysis (PCA)
- Model Evaluation Techniques

> **Note:** The experiments may vary depending on the laboratory syllabus.

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/joseblesse6/ML-LAB.git
```

2. Open the project folder.

3. Install the required libraries.

```bash
pip install numpy pandas matplotlib seaborn scikit-learn
```

4. Launch Jupyter Notebook.

```bash
jupyter notebook
```

5. Open the desired experiment and run the notebook or Python file.
